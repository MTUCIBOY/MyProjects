# Облачное хранилище для ВКР

## Описание проекта

Реализовано REST API облачное хранилище на языке Golang для безопасного хранения данных на отдельном сервере.

Что в него входит:
1. Сохранение/загрузка/удаление файлов
2. Шифрование/дешифрование файлов алгоритмом AES
3. Регистрация/логирование/удаление пользователей
4. Аутентификация пользователей
5. БД для отслеживания состояния сервера
6. TSL подключение к серверу
7. Запуск сервера в контейнере
8. Graceful Shutdown сервера
9. Rate-limit по IP и пользователей в целом
10. Конфигурационный файл с настройками сервера

Какой стек был использован:
1. PostgreSQL, в коде использован чистый PGX.
2. Роутер chi и его middleware.
3. crypto для шифрования файлов, создание секретных ключей и хеширования паролей
4. JWT с алгоритмом HS256
5. Для TSL соединения были созданы сертификаты с помощью программы mkcert
6. mime/multipart для работы с файлами
7. cleanenv для парсинга конфигурационного файла
8. slog из стандартной библиотеки
9. go-chi/httprate
10. gofakeit и httpexpect для тестирования
11. Docker

Если требуется использовать другую БД, был реализован интерфейс, который должен включать в себя все методы, которые использует pkg/storage/postgreSQL: NewUser, NewFile, DeleteFile, DeleteUser, UserID, IsFileExists, AllFiles и ComparePassword. Подробно смотрите в коде.

## Запуск проекта

Для того, чтобы запустить проект для начала нужно создать сертификаты для работы сервера с TSL. Для этого в терминале напишите: ``$ make cert_gen``.
Далее нужно задать переменные окружения. Я рекомендую использовать следующий способ:
1. Создать файл .env
2. Записать в него нужные переменные:
	- BASE_PATH= *путь хранения данных*
	- CONFIG_PATH= *путь до конфигурационного файла*
	- CERT_PATH= *путь до сертификата*
	- KEY_PATH= *путь до секретного ключа*
	 - STORAGE_DSN= *ссылка на подключение к БД*
	 - FILE_ENCRYPTION_KEY= *секретный ключ для шифрования данных*
Пример такоего файла:
``BASE_PATH=./CloudBase``
``CONFIG_PATH=./config/local.yml``
``CERT_PATH=./cert/localhost.pem``
``KEY_PATH=./cert/localhost-key.pem``
``STORAGE_DSN=postgresql://postgres:postgresql@postgres-server:5432/postgres``
``FILE_ENCRYPTION_KEY="V74SfeZmO/8fcW1zWCfRD8OcUqA9Whm8oJIoJlSHohk="``
Для генерации FILE_ENCRYPTION_KEY выполните команду: ``$ openssl rand -base64 32``. Ключ должен быть строго 32 байта!
3. Выполните команду: ``$ export $(cat .env | xargs)`` для того, чтобы загрузить все переменные в терминал

Далее можете запустить облако либо локально, либо в контейнере.

Если хотите запустить сервер локально, то:
1. Выполните команду: ``$ make buildServer``, чтобы собрать бинарный файл
2. Выполните команду: ``$ make upServer``, чтобы запустить бинырнвй файл. На этом этапе у вас уже должена быть запущена БД, иначе сервер сразу же упадет.

Если хотите запустить проект в контейнере, то:
1. Выполните команду: ``$ make buildDocker``, чтобы собрать контейнер
2. Выполните команду: ``$ make upConteiner``, чтобы поднять контейнер. Также автоматически поднимает контейнер с PostgreSQL. Для настроек измените файл docker-compose.yml
